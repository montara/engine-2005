# Engine: an interactive 3d simulation of a 4 stroke engine 

**Features**
- Dynamicly creates a scene with the major internal components of an internal combustion engine. The engine is assembled from it's component parts in any configuration, V, H, or Radial, with correct offsets and journal sizes.
- Combusion forces are applied to the piston surface, and the physics engine transmits those forces to the rod, crank, and ultimately to the engine output.
- Created in Python with pyOgre, tcl/tk, and pyODE (Open Dynamics Engine)
  

This is an archived project from the 2004-2006 timeframe. I created this to better understand object oriented programming, 3d modeling and rendering, and physics simulation.
